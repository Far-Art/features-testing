Focus mode hosts the real control.

The dialog does not rebuild the field. A CDK DomPortal moves the actual element in and puts it back on close, so validators, the value accessor and every live state stay the same instances. Edits are buffered — nothing reaches the control until Apply.

Open a dialog, then press one of these. The dialog follows the control: it turns readonly and its Apply action disappears, without closing.

The dialog footer counts the buffered characters. Where the control carries a maxLength validator it counts against that limit — read from the validator itself, so no maxlength attribute is needed. Apply stays disabled while the buffered value fails validation: shorten the notes below twenty characters, or break the reference pattern, and it greys out. A hint adds whatever the derived metadata cannot know — here, the pattern the reference expects, spelled out.

Fields that would overflow the dialog

These arrive carrying sizing meant for a form row: an explicit cols, a fixed field-width class, and a single unbroken value. The stage clamps every projected child to the dialog width, so the dialog scrolls on one axis only. Narrow the window and reopen them to push it harder.

The last one is written as rows="1". Focus mode still opens it at four rows, and it can be dragged taller but never wider.

Placeholder inside a form grid

While a field is away in the dialog a placeholder, measured from that field before it moves, holds its track open. Open any field here and watch the grid: the neighbouring columns keep their positions and nothing below reflows. The label also stays on its own field rather than jumping to the trigger button.

The address field is four rows tall and the ones above it are single-line, so the placeholder has to match two very different measured heights.

Placeholder in an inline row

In a row the fields share one line, so a collapsing field would pull its neighbour sideways.

Inside a readonly scope

The field inherits the scope and stops accepting edits, while the trigger stays usable and switches to zoom-in — reading a locked value is still allowed.
