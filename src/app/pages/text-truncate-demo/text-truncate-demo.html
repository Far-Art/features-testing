imsTextTruncate · גם בשדות קלט

הדירקטיבה מציגה את הטקסט המלא בחלונית רק כשהוא באמת נחתך. על input ועל textarea היא קוראת את ה־value הנוכחי של השדה, ועל select את האפשרות שנבחרה. היא משאירה לשדה את העיצוב שלו ופותחת את החלונית מתחת לשדה, לא מעליו.

input

שדה בשורה אחת

ערך שלא נכנס בשדה מסתיים בשלוש נקודות, כל עוד אין בשדה מיקוד. שנו את הרוחב ועברו עם העכבר מעל שדה: החלונית נפתחת רק כשהערך נחתך. הקלדה סוגרת אותה, ומעבר העכבר הבא מציג את הערך החדש.

כתובת בעברית

imsInput imsTextTruncate

הערך נקרא מ־value בכל פתיחה, ולכן גם אחרי עריכה החלונית מציגה את מה שבשדה עכשיו — לא את הערך שהדף נטען איתו.

דוא״ל משמאל לימין

type="email" dir="ltr" imsTextTruncate

החלונית לוקחת את הכיוון ואת הגופן מהשדה עצמו, כך שכתובת באנגלית נשארת משמאל לימין גם בדף עברי.

קריאה בלבד

[ims-readonly]="true"

שדה מושבת אי אפשר לגלול, ולכן החלונית היא הדרך היחידה לקרוא בו ערך ארוך. מעבר עכבר פותח אותה גם כאן.

textarea

טקסט בכמה שורות

ב־textarea אין שלוש נקודות: השדה שומר על גלישת השורות ועל פס הגלילה שלו, ונחשב חתוך כשהתוכן ארוך מהשורות שלו. החלונית שומרת על מעברי השורה שבערך.

הערה לעריכה

rows="3" imsTextTruncate

מחקו שורות עד שהכול נכנס בשלוש השורות: מעבר העכבר כבר לא יפתח חלונית. הוסיפו שורה, והיא חוזרת.

קריאה בלבד, עם העתקה

imsTextTruncateInteractive

משדה מושבת אי אפשר לסמן טקסט. חלונית אינטראקטיבית נשארת פתוחה כשהעכבר עובר אליה, ואפשר לסמן בה את הסיכום ולהעתיק אותו.

select

רשימה נפתחת

ב־select[ims-select] הערך נחתך ליד החץ, והחלונית מציגה רק את האפשרות שנבחרה — לא את הטקסט של כל האפשרויות ברשימה. הדירקטיבה לא משנה את הפריסה של השדה, ופתיחת הרשימה סוגרת את החלונית.

מסלול ביטוח

select ims-select imsTextTruncate

בחרו מסלול קצר, והחלונית כבר לא נפתחת: הדירקטיבה מודדת את האלמנט שמציג את הערך, לא את ה־select כולו.

קריאה בלבד

[ims-readonly]="true"

select בקריאה בלבד מושבת, ואי אפשר לפתוח את הרשימה כדי לקרוא בה את הערך המלא. מעבר עכבר מציג אותו בחלונית.

Behaviour

מה משתנה על שדה

  • הטקסט הוא ה־value. ב־input המאפיין textContent ריק, וב־textarea הוא מחזיק רק את הערך ההתחלתי. הדירקטיבה קוראת את value ברגע הפתיחה, וטקסט מפורש ב־[imsTextTruncate] עדיין קודם לו.
  • השדה שומר על העיצוב שלו. שדה כבר חותך את התוכן שלו, ולכן לא נקבעים עליו display, רוחב, overflow או white-space. input ו־select מקבלים רק text-overflow: ellipsis, ו־textarea לא מקבל דבר. imsTruncateDisplay ו־imsTruncateMaxWidth לא חלים על שדה.
  • החלונית נפתחת מתחת. כשלא נקבע imsTextTruncatePosition, החלונית נפתחת ב־bottom אם האלמנט הנמדד הוא שדה, וב־center בכל מקרה אחר — כך היא לא מסתירה את הטקסט שמקלידים.
  • הקלדה סוגרת. אירוע input סוגר את החלונית, ומעבר העכבר או המיקוד הבאים מודדים את הערך החדש.
  • ב־select נקראת האפשרות שנבחרה. ה־textContent של select מחבר את הטקסט של כל האפשרויות, ולכן הדירקטיבה קוראת רק את האפשרות שנבחרה ומודדת את selectedcontent — האלמנט שמציג את הערך ליד החץ. select שהדפדפן מצייר בעצמו לא חושף מה למדוד, ושם רק imsTextTruncateOverflow פותח את החלונית.
  • הרשימה קודמת לחלונית. הרשימה של select נפתחת במקום שבו נפתחת החלונית, ולכן לחיצה על השדה סוגרת את החלונית, והיא לא נפתחת כל עוד הרשימה פתוחה. מיקוד פותח אותה רק כשהוא מגיע מהמקלדת: אחרי בחירה בעכבר השדה מקבל את המיקוד בחזרה מהרשימה.
  • סיסמה לא נחשפת. נקראים רק סוגי input שמציגים טקסט רגיל: text, search, email, url ו־tel.
  • בלי הקראה כפולה. שדה לא מקבל aria-describedby שמצביע על החלונית, כי הערך שלו כבר מוקרא. על כל אלמנט אחר נוסף רק המזהה של החלונית, והפניות שכבר קיימות — רמז, חלונית שגיאה — נשמרות.
  • הדרך לחלונית פתוחה. ב־imsTextTruncateInteractive הרווח שבין השדה לחלונית נחשב חלק מהאזור, כך שהחלונית לא נסגרת בזמן שהעכבר עובר אליה.
